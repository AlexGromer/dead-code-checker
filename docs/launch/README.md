# Launch drafts

Drafts only. Nothing here has been submitted, posted or published. Each file says what has to be true before it is used
and what is still to be filled in. `{{like this}}` marks a value that comes from a measurement or a decision that has not
been made yet; no number appears in these texts until the run behind it exists (see [../methodology.md](../methodology.md)).

| file | what |
|---|---|
| [pypi-checklist.md](pypi-checklist.md) | publishing to PyPI |
| [github-marketplace.md](github-marketplace.md) | listing the GitHub Action |
| [vscode-marketplace.md](vscode-marketplace.md) | VS Code Marketplace and Open VSX listing of the extension |
| [mcp-registry.md](mcp-registry.md) | MCP registry entry (later) |
| [awesome-lists.md](awesome-lists.md) | pull request texts for curated lists |
| [announcements.md](announcements.md) | Show HN, Habr, Reddit, dev.to |
| [comparison-article.md](comparison-article.md) | outline of a comparison with vulture, knip and fallow |

Order that works: PyPI and a tagged release first (everything else links to them), then the Action listing, then the
extension, then the announcements with the measured numbers, the comparison article last.
